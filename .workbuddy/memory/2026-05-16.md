## CVAT UI 汉化（直接替换，非 i18n）

### 目标
在 v2.64.0 tag 上对 cvat-ui 进行完全汉化，直接替换源码中的英文文本为中文，不使用 i18n 国际化框架。

### 操作步骤
1. 先执行了 `git checkout -- .` 丢弃 develop 分支上的汉化修改（该分支上的修改是针对较新代码的）
2. `git checkout v2.64.0` 切换到 v2.64.0 tag（detached HEAD）
3. 编写汉化脚本 `dev/translate_ui.py`，包含 848 个英中翻译词条，支持四种匹配模式：
   - 双引号字符串 `"Text"`
   - 单引号字符串 `'Text'`
   - JSX 内联文本节点 `> Text <`
   - JSX 独占行文本节点（缩进后跟换行）
